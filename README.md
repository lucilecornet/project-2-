## Rock Paper Scissors Game

A simple command-line rock paper scissors game where you play against the computer!

### How to Play

Run the game with:
```bash
python3 rock_paper_scissors.py
```

Choose rock, paper, or scissors when prompted. The game keeps track of your score and you can play as many rounds as you like. Type 'quit' to end the game and see your final score.

### Rules
- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock

Have fun!
